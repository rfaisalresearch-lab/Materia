# Nuclear data shipped with Materia

`mass_1.mas20.txt` is the unrounded atomic mass table of the 2020 Atomic Mass
Evaluation, unchanged, as distributed by the IAEA Atomic Mass Data Center
(https://www-nds.iaea.org/amdc/). Cite:

* W. J. Huang, M. Wang, F. G. Kondev, G. Audi and S. Naimi, Chin. Phys. C 45
  (2021) 030002.
* M. Wang, W. J. Huang, F. G. Kondev, G. Audi and S. Naimi, Chin. Phys. C 45
  (2021) 030003.

SHA-256: `e8599c6d7f724fac91934e59f1b9de8fb8f63e820f4b39456b790665ed2a3307`.
`materia.physics.nuclear` refuses to read the file if the checksum differs.
